# מילולי 🧩

משחק מילים בעברית: האותיות מעורבבות, הזמן רץ - סדרו את האותיות וגלו את המילה הנסתרת.

## איך משחקים
- 12 סיבובים, בכל סיבוב מילה מעורבבת מקטגוריה עם רמז
- 45 שניות לסיבוב, ניקוד לפי אורך המילה + בונוס זמן + בונוס רצף
- כפתור רמז חושף את האות הראשונה (במחיר נקודות), כפתור דילוג מפסיד את הסיבוב
- שיא אישי נשמר מקומית, כפתור שיתוף לחברים

## טכנולוגיה
HTML/CSS/JS טהור בקובץ יחיד, ללא תלויות. RTL מלא, מותאם מובייל.
